## 💡 В чём идея

Большинство портфолио устроено одинаково: вертикальный скролл, пара карточек и сухая форма контактов.  
**PORTFOLIO 95** переворачивает формат — **сам сайт является рабочим столом**, на котором можно открывать окна, перетаскивать их, рисовать в Paint, играть в Сапёр, слушать синтезатор, вводить команды в MS-DOS и исследовать кейсы прямо внутри системы.

> **Демо:** 👉 **[https://joludii33.github.io/portfolio-95/](https://joludii33.github.io/portfolio-95/)**

## 🎮 Оконный менеджер и управление

- **Перетаскивание окон** — хватай любое окно за верхнюю синюю/серую шапку.
- **Сворачивание, разворачивание и фокус** — кнопки `[_]`, `[□]`, `[×]`, двойной клик по шапке, переключение и восстановление через панель задач снизу.
- **Меню «Пуск»** — мгновенный запуск всех программ в один клик, настройки экрана и диалог *«Завершение работы...»*.
- **Звуковой движок** — чистый Web Audio API (ретро-клики, ошибки, победный сигнал, мелодия загрузки и чиптюн-синтезатор), выключается кнопкой `🔊` в трее.

<details>
<summary>🕵️ <b>Секреты и команды MS-DOS (нажми, чтобы раскрыть спойлеры)</b></summary>

Открой **MS-DOS** на рабочем столе и попробуй ввести:

```dos
help       — полный список доступных команд
about      — досье автора
projects   — список проектов на диске C:
skills     — ASCII-шкала навыков
dir        — содержимое директории C:\KRAVTSOV
paint      — запустить Paint 95 из консоли
mines      — запустить Сапёр.exe
player     — запустить Плеер.exe
bsod       — 💥 вызвать легендарный Синий Экран Смерти (выход — любой клик)
```

Также Синий Экран можно вызвать через **Пуск → Завершение работы... → Вызвать Синий Экран (BSOD)**, а в **Корзине** попробуй открыть `пароль_от_интернета.txt`.

</details>

## ⚙️ Технологии

- **React 18** + **Vite 6** — быстрая сборка и модульная архитектура окон.
- **Чистый CSS (3D-фаски Win95)** — аутентичные двойные тени, пиксельные шрифты (`Silkscreen`, `IBM Plex Mono`, `PT Sans`), 5 стилей обоев и CRT-эффект.
- **Web Audio API** — 100% процедурный звук и чиптюн-плеер без внешних аудиофайлов.
- **HTML5 Canvas & Inline Pixel SVG** — собственная рисовалка Paint 95 и чёткие 16-битные иконки.

## 🚀 Локальный запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Joludii33/portfolio-95.git
cd portfolio-95

# 2. Установить зависимости
npm install

# 3. Запустить локальный сервер
npm run dev
```

Сборка продакшн-версии (готовой к загрузке на GitHub Pages):

```bash
npm run build
```

## ✏️ Как заменить данные на свои

Весь контент (имя, описание, навыки, 5 проектов, контакты и содержимое Корзины) вынесен в один файл:

```text
src/data/win95Data.js
```

Отредактируй его, выполни `npm run build` — и готово!

## 📂 Структура проекта

```text
├── .github/workflows/deploy.yml   # Автодеплой на GitHub Pages
├── index.html                     # Точка входа и подключение шрифтов
├── vite.config.js                 # Конфиг Vite с относительными путями (base: './')

    ├── App.jsx                    # Рабочий стол, менеджер окон, бут-скрин и диалоги
    ├── index.css                  # Дизайн-система Windows 95, обои и CRT-режим
    ├── data/win95Data.js          # Все тексты, проекты, навыки и обои
    ├── utils/retroSound.js        # Web Audio API звуковой движок
    └── components/
        ├── Win95Window.jsx        # Перетаскиваемое окно Win95
        ├── Taskbar.jsx            # Панель задач, «Пуск» и трей с часами
        ├── PixelIcons.jsx         # Пиксельные SVG-иконки
        ├── BsodScreen.jsx         # Пасхалка Синий Экран Смерти
        └── apps/
            ├── PortfolioApps.jsx  # Мой компьютер, Проекты, IE 95, Блокнот, Почта, Корзина, Экран
            └── FunApps.jsx        # Paint 95, Сапёр, Чиптюн-плеер, MS-DOS
```
